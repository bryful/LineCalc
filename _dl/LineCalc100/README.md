# LineCalc

Windows用の、入力欄が1つだけの計算機です。JavaScriptの式・条件分岐・ループ・ユーザー関数を実行できます。ウィンドウは横幅を変更でき、高さは1行分です。タイトルバーには閉じるボタンだけを表示します。

## 起動と操作

Windows 10／11の64ビット環境で `LineCalc.exe` を起動してください。起動時は最前面に表示します。

最前面表示が有効な間は、非アクティブになると入力欄を隠してタイトルバーだけの高さに縮めます。クリックやAlt+Tabでアクティブにすると1行表示へ戻り、入力内容と選択範囲を保持します。`setTopmost(false)` の場合は、非アクティブになっても通常サイズを維持します。縮小時も横幅と位置は変えません。

| 操作 | 動作 |
| --- | --- |
| Enter | 入力を実行し、同じ欄に結果を表示 |
| ↑／↓ | 入力履歴を移動。未確定の入力・編集した履歴も保持 |
| ←／→、Home／End | カーソル移動 |
| Ctrl+A、Ctrl+C／X／V | 全選択、コピー／切り取り／貼り付け |
| Shift+F1～F12 | 表示中の数値結果、または入力を評価した数値結果をメモリへ保存 |
| F1～F12 | メモリの値をカーソル位置へ挿入。選択範囲があれば置換 |

成功すると `OK` が500ms表示されます。エラー時は確認画面が開き、入力した式はそのまま残ります。エラーの式も履歴に保存します。結果はそのまま編集できます。

OK通知とエラー・一覧の確認画面は、アプリがあるモニターの表示可能な範囲内に配置します。下側に余裕がない場合は上側に表示し、タスクバーや画面の外に隠れないよう位置を調整します。

## 計算例

```javascript
(15-2)*12
Math.sin(Math.PI/2)
0x001+0b00000001_11000001
foo=(15-2)*12
foo
a=1;b=12;a+b;
a=0; for(var i=0;i<10;i++) a+=i; a;
function triple(v){ return v*3; }
triple(5)
```

三角関数の角度はラジアンです。変数は数値専用で、`var foo`／`let foo` の初期値は0です。宣言・関数定義だけの実行は空欄になります。`a=1` は1を表示し、`a=1;` は空欄にします。最後が値を返す式なら、`a+b;` のように末尾にセミコロンがあっても結果を表示します。

`ans` は直前の数値結果です（初期値は `null`）。エラーや結果なしの実行では更新しません。メモリは `M1`～`M12` として使えます。初期値は `null`、`M1=null` で消去、`M1=0` は数値0を保存します。空メモリのFキー挿入は `null`、負数は括弧付きです。これらの予約名は再宣言できません。

## 組み込み関数

| 関数 | 動作 |
| --- | --- |
| `resetJS()` | 現在の実行を終了し、変数・関数・メモリ・ansを初期化して定義ファイルを再読み込み。履歴と最前面設定は保持 |
| `setTopmost(true)`／`setTopmost(false)` | `true`で他のウィンドウより手前に常時表示し、`false`で解除。引数省略時は解除。アプリ起動時は有効 |
| `isTopmost()` | 最前面表示が有効なら`true`、無効なら`false`を返す |
| `clearHis()` | 上下キーで呼び出す入力履歴をすべて削除する。入力欄に現在表示されている文字は消さない |
| `clearMem()` | 全メモリをnullにする |
| `help()`／`help("resetJS")` | 全体のヘルプ、または指定した名前の説明 |
| `vars()` | 定義済み変数一覧 |
| `funcs()` | ユーザー定義関数一覧 |
| `mem()` | メモリ一覧 |
| `hex(value)` | 整数を`0x`付きの16進数に変換（例：`hex(255)` → `0xff`） |
| `bin(value)` | 整数を`0b`付きの2進数に変換（例：`bin(10)` → `0b1010`） |
| `fonts()` | インストール済みのフォント名を一覧表示 |
| `setDisplayFont(name,size)` | 入力欄のフォント名とポイント数を設定 |
| `chooseDisplayFont()` | Windowsのフォント選択画面を開く。入力欄からのみ使用可能 |
| `getDisplayFont()` | 現在のフォント設定を、コピー可能な設定行として表示 |

一覧・ヘルプは、テキストを選択・コピーできる確認画面で表示します。

フォントを変更する場合、`fonts()` で名前を確認するか、`chooseDisplayFont()` で見た目を確認して選択してください。`setDisplayFont("Consolas",14)` のようにフォント名と1〜200ポイントのサイズを指定できます。初期設定は `Segoe UI` の12ポイントです。表示する書体は標準スタイルで、フォントファイルのパス指定には対応していません。

サイズを変えると入力欄とウィンドウの高さも1行分に調整され、横幅は維持します。不正な名前・サイズの場合は設定を変更せずエラーにします。選択画面のキャンセルでも現在の設定を維持します。

`getDisplayFont()` で表示された `setDisplayFont("Consolas", 14);` などの行を定義ファイルに貼り付けると、次回の起動にも適用できます。`resetJS()` 自体は表示フォントを初期化しませんが、再読み込みした定義ファイルから変更できます。`fonts()` と `getDisplayFont()` は定義ファイル内では画面を表示せず、`chooseDisplayFont()` はエラーになります。`-debug` でもフォント名・サイズの検証を行います。

`hex()`／`bin()`の引数は、±9,007,199,254,740,991以内の整数に限ります。小数・NaN・無限大・文字列はエラーです。16進数の英字は小文字で、ゼロ埋めは行いません。負数は `-0xff`／`-0b1010` のように符号を付け、補数表現にはしません。

返り値はJavaScriptの文字列ですが、数値を表す `0x`／`0b` 形式の文字列結果は入力欄にそのまま表示し、その数値で `ans` を更新します。Shift+F1～F12でのメモリ保存にも対応し、Enterで再評価すると通常の数値表示になります。通常の文字列結果はエラーのままです。変数への文字列代入も引き続きエラーなので、数値変数には変換前の数値を保存してください。

## 関数定義ファイル

既定の読み込み先は `%LOCALAPPDATA%\LineCalc\LineCalc.js` です。実行ファイル名を変更した場合、同じ名前で拡張子を `.js` に変えたファイルを使用します。UTF-8で保存してください。ファイルでは複数行の関数定義が可能です。

```javascript
function triple(v) {
    return v*3;
}
setTopmost(false);
```

別のファイルを読み込むには、次のように起動します。

```text
LineCalc.exe -include "C:\My Files\functions.js"
```

指定ファイルが存在する場合はそのファイルだけを読み込みます。存在しなければ既定ファイルを読み込みます。読み込み・実行エラーは通知しません。実行途中のエラーでは、それまでの定義・代入は残ります。定義ファイル内では `resetJS()` を実行できません。

ファイル名だけを指定した場合、`-include` と `-debug` はカレントディレクトリを先に探し、見つからなければ `%LOCALAPPDATA%\LineCalc` を探します。親ディレクトリを含む相対パスはカレントを基準に、絶対パスはそのまま使用します。

## 定義ファイルの検証

定義ファイルの雛形を作るには `-createjs` を使用します。

```text
LineCalc.exe -createjs
LineCalc.exe -createjs functions.js
LineCalc.exe -createjs ./functions.js
LineCalc.exe -createjs "C:\My Files\functions.js"
```

パス省略時は既定の定義ファイル、ファイル名だけの場合は `%LOCALAPPDATA%\LineCalc` 内に作成します。`./functions.js` はカレントに作成し、親ディレクトリを含む相対パスもカレント基準です。必要な親ディレクトリは作成します。

雛形はUTF-8で、組み込み関数の説明・呼び出し例とユーザー関数の例をすべてコメントにして保存します。既存ファイルは上書きしません。作成結果を確認すると終了します。`-debug`／`-include`とは併用できません。

```text
LineCalc.exe -debug
LineCalc.exe -debug "C:\My Files\functions.js"
LineCalc.exe -debug functions.js
LineCalc.exe -debug -include functions.js
```

`-debug` は通常の計算画面を開かず、定義ファイルを読み込み・評価します。パス省略時は既定の定義ファイルを使用します。`-include` を併用する場合はそのファイルを使用し、`-debug` 自体にもパスがある場合はそちらを優先します。

問題がなければ `OK`、問題があればファイル名とエラー位置・内容を確認画面に表示します。OKボタンで閉じると終了します。終了コードは成功時0、失敗時1です。デバッグで明示したファイルが見つからない場合、別のファイルには切り替えずエラーを表示します。

構文検査に加えて、ファイルのトップレベルの文も実行します。関数本体の実行時エラーは、その関数をファイル内で呼び出した場合に検出できます。通常起動時と同じく、定義ファイル内の `resetJS()` はエラーです。

## データとトラブルシューティング

履歴・変数・関数・メモリはアプリ起動中だけ保持し、終了時に消去します。定義ファイルは変更しません。

ウィンドウの位置とサイズは、終了時に `%LOCALAPPDATA%\LineCalc\LineCalc.json` に保存して次回起動時に復元します。高さは1行分を維持し、タイトルバーだけに縮小中でも通常表示のサイズを保存します。モニターの変更などで画面外になる場合は、タスクバーを除いた画面内へ補正します。`-debug` と `-createjs` は位置とサイズを保存しません。

ゼロ除算、NaN、無限大、構文エラーなどはエラーになります。JavaScriptの `null` と真偽値は結果として表示できます。計算には実行時間2秒の上限があるため、終了しないループも中断されます。丸め誤差はJavaScriptの数値計算に従います。

## VS Code拡張機能

定義ファイルの編集・検証・実行には、[LineCalc for VS Code](vscode-linecalc/README.md)を利用できます。VSIXをインストールし、`LineCalc::RegisterExecutable` でLineCalc.exeを登録してください。`LineCalc::OpenIncludeDir` で既定のフォルダを開き、`LineCalc::debug`／`LineCalc::include` で現在の.jsを検証・実行できます。`LineCalc::Open`は編集中のファイルに関係なく計算機を通常起動します。組み込み関数の補完と説明表示にも対応します。
