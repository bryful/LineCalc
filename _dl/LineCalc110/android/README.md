# LineCalc for Android

JavaScriptの式・変数・ユーザー関数を使える、1行入力の計算機です。Android 10以降の64ビット端末に対応します。

画面は上から「履歴・メモリ・関数・再読込・その他」「入力行」「専用キーボード」で構成します。入力行の右側またはキーボードの「実行」で計算します。`=` キーは変数への代入用です。結果は同じ欄に表示され、そのまま編集できます。

専用キーボードは「数値」「英字」「JS」の3面を切り替えて使えます。英字はQWERTY配列で、⇧で大文字・小文字を切り替えます。数値面の `×`・`÷`・`−` はそれぞれ `*`・`/`・`-` を入力します。

横画面では数値・JSキーを3行に並べ替えます。ボタン名は1行で表示し、文字サイズはボタンの幅と高さに合わせて調整します。

`⌫` は選択範囲または直前の文字を削除し、`◀`・`▶` はカーソルを移動します。いずれも長押しで連続操作できます。`AC` は入力行だけを消去し、変数・メモリ・履歴は保持します。面を切り替えても入力内容と選択範囲を維持します。コピー・貼り付けは入力行の長押しから操作できます。

日本語入力などが必要なときは「⋮ → 標準キーボードに切替」を使用します。同じメニューから専用キーボードに戻せます。キーボードの種類は次回起動にも引き継ぎます。

```javascript
(15-2)*12
Math.sin(Math.PI/2)
function triple(v){return v*3;}
triple(5)
```

`ans` は直前の数値結果、`M1`～`M12` はメモリです。上部のメモリボタンから入力式の数値結果を保存したり、値を挿入・消去したりできます。履歴と関数は一覧から入力欄へ挿入できます。物理キーボードのEnter、↑／↓にも対応します。

## 初期読込JS

初回起動時に `Documents/LineCalc/LineCalc.js` を自動作成します。フォルダー選択は不要です。既存のファイルは上書きしません。ファイルはUTF-8で保存し、外部のテキストエディターやPCから編集できます。「⋮ → 定義JSを編集」から対応するエディターを開くこともできます。

編集した内容は次回起動、上部の再読込、または `resetJS()` で反映します。再読込は変数・関数・メモリ・ansを初期化します。履歴と入力行は保持します。「⋮ → 定義JSを検証」は現在の計算状態を変更せず、別の環境で定義ファイルを実行して確認します。

読込先は「⋮ → 設定 → 読込フォルダーを変更」で後から変更できます。選択先に `LineCalc.js` がなければ雛形を作成します。元のファイルは移動・削除しません。

アプリ再インストール後、外部エディターによるファイルの置き換え後、アクセス権の失効時などに読み込めなくなった場合は、設定から該当フォルダーを選択し直してください。読込エラーは画面に表示し、基本計算は引き続き利用できます。アプリ削除時も共有フォルダーのJSは残ります。

## 制限とデータ

計算の実行時間上限は2秒、初期JSのサイズ上限は4MiBです。エラー時は入力式を保持します。画面回転や一時的なバックグラウンド移行では計算状態を保持し、プロセス終了時には履歴・変数・関数・メモリを消去します。

Windows専用の最前面表示・フォント関連関数は非対応です。計算規則はWindows版と共通です。ネットワーク接続は使用しません。
